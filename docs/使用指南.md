# ObManage 使用指南

ObManage 把选定来源的文件状态镜像到另一边。新增、修改、删除都会同步，来源仅被读取；目标独有文件会被清理。操作前应选择当前工作成果所在的一边作为来源。

## 路径与方向

界面固定显示“本机仓库”和“移动硬盘仓库”，两行都可以修改。默认本机位置为当前用户桌面的 `Obsidian仓库`，移动硬盘位置为 `H:\ObsidianVault\Obsidian仓库`。盘符可以不同，选择的文件夹就是最终镜像根目录。

“带到移动硬盘”以本机为准、更新移动硬盘；“带回本机”以移动硬盘为准、更新本机。两边都独立修改时，需要先自行决定哪边是本次来源；程序不会合并冲突或优先采用时间较新的文件。

## 手动同步

1. 核对两个仓库路径与同步方向。
2. 点击“分析差异”。分析只读取仓库，同时把已完成校验的记录保存在本机应用数据目录。
3. 查看待执行变化。表格中的“实际修改位置”是目标文件位置；过长路径可悬停查看或右键复制。可以切换分类查看删除或跳过的文件。
4. 勾选方向确认，点击“更新本机”或“更新移动硬盘”。普通删除已包含在本轮同步中。

若来源完全为空而目标有内容，会额外要求确认清空目标。完成后再次分析，无变化文件不会复制。选择新的路径、方向或重新分析都会清除旧预览和确认。

## 定时与托盘

定时默认关闭。开启后可选择间隔（初始值为 60 分钟）或每天指定时间，按电脑本地时间运行。**开启定时代表授权当前方向自动镜像，包括删除。**

- 开启定时后，关闭窗口会进入系统托盘，继续按时运行。
- 托盘可打开窗口、立即分析差异、暂停定时或退出；立即分析后需在主界面确认再手动更新。
- 程序同时只运行一个任务，忙碌时到点会跳过该次，不累计任务。
- 切换方向或修改任一仓库路径，会暂停定时；重新开启时绑定当前方向和路径。
- 磁盘未连接时记录跳过原因，下次到点重新检查；空来源可能清空目标时暂停定时，需手动处理。
- 明确“退出”会停止后台运行。本版本不安装 Windows 服务或开机启动项。

## 大文件、校验与恢复

首次接管同大小文件需要读取两边内容做 SHA-256 比较。视频较多时校验可能较慢，但相同内容不会重新写入。已完成的记录会保留，取消后可以继续。

日常快速检查依赖每端大小和精确修改时间。“完整内容校验”会绕过快速记录，重新读取两端的每个文件并做 SHA-256，适合检查大小与时间都未改变的内容异常。本机与移动盘位于不同卷时会并行读取，因此不用再把两端读盘时间完全相加；它仍是全量校验，不是抽样，最终速度仍受较慢磁盘限制。校验结束仍是预览，需要确认后才更新。

普通复制写入目标盘临时文件，完成后替换正式文件；新增和更新完成后才清理多余项。取消或失败时已完成部分保留，后续删除停止。排除磁盘空间不足、文件占用或设备断开等问题后，重新分析再执行即可。内容变化的大文件按整个文件复制。

## 同步内容与日志

同步包含隐藏文件、`.obsidian` 配置、空文件夹和普通子目录，支持中文和 Windows 长路径。文件与目录同名冲突、链接和其他重解析点会报错，需处理后重新分析。NTFS 权限、备用数据流和历史版本不在同步范围内。

配置、SQLite 校验记录和日志位于 `%LOCALAPPDATA%\ObManage`，不会写入来源仓库。界面的“查看日志”提供任务结果和失败原因，`obmanage.log` 保存持久运行记录。

便携程序需要保留 `ObManage.exe` 旁边的 `_internal` 文件夹；移动时复制整个程序目录，无须安装 Python。
