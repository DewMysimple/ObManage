## 复现与写入保护

使用专用 Windows 本机白名单文件，直接存放在经核验的系统临时目录。JSON 对象只包含 `local` 和 `portable` 两个绝对路径。电脑端路径位于指定来源盘卷根下一级，移动端路径位于独立的移动盘父目录下，集合名一致。报告和本轮 SQLite 位于系统临时目录下的私密目录。白名单及报告留在本机。

```powershell
.\.venv\Scripts\python.exe -X utf8 tools\experiment_initial_sync.py --dry-run --allowlist $localAllowlist
.\.venv\Scripts\python.exe -X utf8 tools\benchmark_initial_sync.py --files 1000 --rounds 3
```

本机现场执行需在交互终端显式传入 `--execute`，逐次输入当前预览专用短语。预览过期或路径、身份、原始清单变化立即拒绝。已存在非空目标停止。正式执行占用应用实例锁并在检查点确认仍持有此锁，同时检查部署及遗留回收站恢复状态。

试跑选一个较小的非重叠仓库。余下仓库重新生成预览。进程内账本保留独立核验的目标清单和源/目标等价摘要，下一批会重新读取完成范围的源与目标并与账本比对，检查集合内是否新增了陌生对象。退出或失败后保留已完成的文件和目录。本轮流程的现场确认及账本只在同一次进程有效。

原生增量执行保留整批预检、逐仓库检查和停错规则。实验额外要求缺失的仓库根、逐项精确的新增计划、原子独占创建目录、文件句柄核验及无替换提交。若同名对象在最后一次路径检查后到达，Windows 拒绝发布，原对象保留。暂存清理由拥有的文件句柄完成。默认镜像继续采用原有更新及删除语义。阶段计时复用现有指标。可查阅 [Windows 目录创建接口](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/wdm/nf-wdm-zwcreatefile) 和 [文件重命名结构](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-file_rename_info)。

独立核验重新枚举原始名称空间，比较文件、空目录、名称、普通文件大小及两侧分别读取的 SHA-256。目录及文件快照还要在核验结束后重新读取。时间精度差异单独计数。哈希读取范围是普通文件的默认数据流。读取可能使操作系统更新访问时间。

合成小文件集中在元数据调用，来源读取及缓存写入的累计用时较低。实际 USB 写入、延迟回写和大文件的占比需要真实写入数据确定。原有镜像两版区间重叠，当前未引入针对吞吐的生产优化。已采用的改动是独占新增保护和可选指标。真实首次复制的性能提升未证明。

另在全量回归间隙独立运行三轮。旧版执行 12.217 秒 [9.731–12.472]，当前版同语义 12.485 秒 [12.472–12.515]，仅新增带指标 12.935 秒 [12.924–13.117]。快速复扫分别为 1.368、1.381、1.346 秒，完整内容复扫分别为 3.846、4.071、3.888 秒。每轮的命中与实际哈希量等同于上表。两组系统状态不同，无法用其中一组的快慢推断真实设备。无需为追求跑分引入并发或减少屏障。

三轮隔离取消在 24 MiB 文件暂存到 4 MiB 时发出取消，进程返回并完成暂存清理的中位数为 2.89 ms [2.82–3.41]。每次均发布 0 个文件。该进程生命周期峰值工作集约 55.2 MiB，测量包含夹具初始化。真实 USB 阻塞、断连和取消延迟均未实测。

## 工程验收

Windows 全量回归 813 项通过，其中 32 项为首次复制实验用例。额外隔离检查通过 Windows 保留名称、大小写碰撞、已登记暂存被替换及管道输入拒绝执行。真实移动盘热拔插、空间耗尽和掉电未用于故障注入。

便携 ZIP 生成后完成 236 项 CRC 检查、平铺根目录和随附指南比对。解压 EXE 的八个页面均成功启动，隔离完整内容预览通过。实验的真实写入、独立后验 SHA-256 与无变化复扫均为 NOT_RUN。版本对照只在合成数据执行。
