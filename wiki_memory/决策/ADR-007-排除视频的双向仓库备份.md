# ADR-007｜排除视频的双向仓库备份

## 背景与决策

容量有限的笔记本需要保留可工作的 Obsidian 仓库副本，同时完整仓库继续放在移动硬盘。新增独立“仓库备份”页，固定显示笔记本轻量仓库和移动硬盘完整仓库；每轮仍只选择一个来源，以来源为准镜像全部非视频普通文件和目录。来源只读，非视频目标独有内容属于删除范围，不做两端冲突合并。

视频排除必须发生在无 Qt 的同步引擎扫描和计划层，不能只隐藏界面行。来源视频不比较内容、不复制；目标视频不覆盖、不删除；包含目标视频的目录不计划为多余空目录删除。预览以 `exclude` 项明确显示这些路径。视频按共享、大小写不敏感的扩展名集合识别；为避免把 TypeScript 源码误判为 MPEG transport stream，`.ts` 不在排除集合中。

普通完整镜像继续使用原有 pair identity；无视频模式在相同路径/卷标识外增加稳定 profile 命名空间。两种模式的 SHA-256 等价记录和崩溃暂存记录不能交叉复用。计划同时绑定模式、路径、磁盘和扫描快照，执行时复核；修改模式或路径会拒绝旧计划。

## 理由和影响

笔记本能够在不存放大视频的情况下编辑 Markdown、画布、图片、音频、PDF、配置及其他普通文件，再把这些变化带回移动硬盘。代价是这是按扩展名过滤，不读取 MIME；未知扩展名的视频会按普通文件同步。文件夹仍属于非视频结构，因此来源中只含视频的文件夹可能在轻量仓库形成空目录；目标中承载被排除视频的目录必须保留。

页面沿用只读分析、完整内容校验、差异分类、方向确认、空有效来源额外确认、可取消后台任务、全局单任务槽和恢复门禁。首次默认笔记本端为当前用户桌面的 `ObsidianTest`，保存后使用页面自己的设置命名空间。
