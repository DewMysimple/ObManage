# ADR-004｜工程记忆与每轮交付

## 背景与决策

用户明确要求根据提供的工程记忆模板建立本项目记忆，整理公开 README 和 Agent 协作规范，并要求每次完整对话产生的修改都提交、推送。

采用仓库内 `wiki_memory/`：当前状态给出简短工作入口，ADR 保存重要决定，知识页解释稳定模块与操作，日志记录每轮实际结果。保留模板的来源追溯、状态字段和无依赖 lint；正文采用 GitHub 可直接阅读的 Markdown 链接，日志允许进行中的 `draft`。

已明确授权、可由源码或用户要求验证的事实直接进入 `active`。新猜想和未经授权的改变保持 `proposed`，不把模板的候选确认流程用于再次确认用户已授权内容。结束前更新记忆、执行必要检查、提交本轮修改、推送并核对远端。

## 理由和影响

后续协作者能快速掌握删除安全边界与历史原因，Git 历史保留可核对的交付。文档可能变旧，因此每次修改仍需以当前源码为准。公开提交不能泄漏私有仓库内容、凭据或机器路径；本地构建产物与运行数据不进入 Git。
