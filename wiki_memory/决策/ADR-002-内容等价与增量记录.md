# ADR-002｜内容等价与增量记录

## 背景与决策

已有镜像中的大视频不应因为两个磁盘时间戳表示不同而重写。首次遇到同路径同大小文件，分别做 SHA-256，内容相同则逐文件保存已验证记录并跳过。之后分别比较两侧各自的完整快照，任一不匹配才重新判断；不要求 source.mtime 等于 target.mtime。

SQLite 主键为有序的规范路径、两侧磁盘身份生成的 pair_id 加相对路径。大小、纳秒修改时间、ctime、设备与文件身份均属于实际快照。反向记录只有在对调后两端快照都精确匹配时才复用，并写入当前方向记录；深度校验绕过正反两个缓存。

## 理由和影响

已完成哈希逐条提交，所以首次接管取消后无需重读所有已验证文件。路径/卷/方向隔离避免错误复用；反向等价复用改善往返性能。首次内容确认仍有读取成本，快速扫描仍依赖元数据，不等价于每次读取全部内容。
