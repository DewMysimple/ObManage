# 增量异常快退与实时复核精修

用户要求按 2.8.1 迭代文档执行异常快退、末次复核和元数据精修。基线为本地 2.8.0 提交 `2bb5c3e`，各版本在同一 Windows NTFS 临时卷上使用独立 SQLite。原有未跟踪 `prompt/` 留在工作区。

## 实现

- 两端首次发现和配对已阻断整批时，在 SQLite、内容比较及第二轮采集之前返回不完整。保留路径与原因，页面显示整批无法执行。单个初次比较错误仍以仓库行报告。
- 正反方向直接比较同一实时末次清单，只共享相同预期的成功比较，独立检查各自根与锚点。末次发现变化或读取失败时，整批没有 `validated` 授权。执行前复核、逐项核验和删除屏障保留。
- 仓库发现、会话观察与统计复用同次祖先链返回的叶状态。保留祖先链、真实枚举和枚举后的快照。可关闭的聚合诊断分类记录目录、标记、路径快照、读取和 SQLite 提交。

## 阶段验收

改动前复测、A/B、计数及关闭诊断耗时见[扫描架构与性能优化](../../docs/扫描架构与性能优化.md)。阻断性权限异常的目录枚举为 1,124 → 562 次，数据库连接为 1 → 0 次。末次正常扫描保留 510 次目录枚举，减少 462 次路径请求。正常统计保留严格 UTF-8 和错误可见性。对照覆盖 12 及 24 个独立仓库，各加一个嵌套仓库。

24 仓库关闭诊断时，最终两种权限场景分别为 1.811 → 0.717 秒和 3.627 → 0.726 秒。正常首次基本持平，无变化和同大小修改复扫分别缩短 0.8% 和 2.8%。完整末次复核墙钟没有稳定提速证据。

最终源码全量回归 712 项通过，耗时 169.48 秒，无失败或跳过。原生八页在小窗口、普通窗口和最大化尺寸共 24 次检查通过，增量故障提示额外检查三次。故障路径完整显示一次，执行入口禁用。

`tools/build.py` 用最终源码构建便携包。ZIP 共 236 项、51,009,557 字节，CRC 与平铺根结构通过。解压 EXE 的八个页面均启动并退出码 0，完整内容只读 CLI 预览也通过。记忆检查覆盖 64 页。

无已授权物理 USB/exFAT 测试设备。已记录专用测试目录内的合成复现方法，设备身份更换用故障注入验证。未加入跨页历史缓存。
