# 事务工作台简化

## 目标与授权

用户要求审核并简化“事务处理”工作台，减少重复确认和冗余入口。本轮修改界面和操作编排；开发执行仅使用隔离临时仓库，没有处理真实用户事务。

## 实现

- 进入页面、切换事务和刷新列表后自动通过现有全局后台任务槽只读检查；检查中禁用操作，失败可刷新重试。自动检查定时器随页面销毁，避免关闭后访问已销毁控件。
- 待处理事务显示保留现状和保全回退；已结束事务仅显示清除副本及记录、仅删除记录。路径详情默认收起，副本数量常驻，重复状态行和无记录区域隐藏。
- 保留现状按钮直接结束认证事务，保留仓库和全部副本，明确不代表同步完整成功。删除和回退各只弹一次确认，取消为默认，完整路径可在弹窗展开；切页或选择变化使弹窗绑定的旧预览失效。
- 旧版隔离批次清理成功后同一任务内移除记录；清理失败保留记录供重试，已清理的历史批次只显示删除记录。无需清理完成后再手动删除一次。
- 引擎的认证、修订、磁盘及目录身份、预览复核、未知内容保护、原授权边界和全局恢复门禁继续生效。版本更新为 2.6.1，README 与便携指南同步操作说明。

## 验证

- 最终源码全量 `pytest -q`：559 项通过；事务流程与三尺寸布局专项：48 项通过。
- 回归涵盖自动检查和批次切换、保留现状解除门禁、一次确认回退/清除/仅删记录、取消与确认中切页零写、副本变化拒绝删除、旧版清理成功一并删除记录及失败保留重试。
- Windows 原生截图检查 980×620、1140×920 和真实最大化；全页三尺寸布局回归通过，无横向滚动，展开详情仍可访问完整路径。确认弹窗默认取消，中文路径展开/收起通过检查。
- `tools/build.py` 使用原干净子进程 PATH 成功生成 2.6.1 便携程序和 `dist/ObManage.zip`。重建前确认目标目录没有重解析点，仅按工作区 EXE 完整路径结束一个旧实例并等待退出。
- ZIP 全包 CRC、根层 EXE/`_internal`/说明/许可证结构、包内 EXE 与生成文件一致、说明与最终源码文档一致均通过。
- 冻结 EXE 在隔离临时状态下，以待处理和已结束事务分别启动截图成功；自动检查前后仓库及副本内容、事务修订未变化。
- 记忆索引刷新、格式与链接检查、`git diff --check` 通过。
