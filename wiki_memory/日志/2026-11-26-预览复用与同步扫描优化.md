# 预览复用与同步扫描优化

用户要求在看过差异后直接同步，完整内容校验直接运行，并排查各页面的重复扫描。旧版在镜像和备份页启动同步时清除页面计划，即使刚刚看过预览，也会重做两端的初次扫描、内容比较和分析结束扫描，再弹出确认。

## 各页处理

| 页面或机制 | 本轮处理 |
| --- | --- |
| 镜像、无视频备份 | 独立预览与完整校验生成可消费一次的计划。点击同步即确认已显示的方向和差异。执行预检重新采集两端清单，过期在写前停止。清空有效目标时单独确认。表格筛选只取动作字段。 |
| 直接、定时镜像 | 有变更且来源非空时，当前引擎的候选在确认后的执行预检核实。无变化结果、空来源和独立预览仍在分析结束时复核。定时到点独立分析。 |
| 完整内容校验 | 一次 SQLite 事务按仓库对及模式退役双向记录，省去读取和反序列化即将删除的旧记录。同大小配对文件重新读取完整 SHA-256。 |
| 逐仓库增量 | 按目录祖先检测所选范围重叠。每个仓库的待复制字节仅汇总一次，后续进度按常量取值。批次结束复核、写前整批预检和每仓库执行复核保留。 |
| .comSync | 实时核对候选。目标无需关闭窗口时，直接从本次分析取真正需要写入的组件。若冻结请求和完整预览一致，同步点击即确认。若关闭过窗口，重读保存结果并确认最终范围。文件差异同时给出子树替换判断。 |
| 统计、事务处理 | 统计按类别一次归并扩展名并排序。事务检查和部署进度复用本次不可变目录树的文件列表与容量。 |
| .Trash、.Archive | 回收站遍历复用当前安全子路径检查取得的叶快照。ZIP 归档复用目录链检查的叶快照，按序比较完整清单，保留包内校验、来源重读与发布前检查。 |

预览后的实时复核读取当前文件元数据。目录枚举对象可缓存属性，长期持有不能证明文件仍处于预览状态。深度校验只删除当前模式、当前仓库对的匹配行。在本项目中分别落实为实时执行预检及带条件的单事务删除。[Python 3.14 目录项](https://docs.python.org/3.14/library/os.html#os.DirEntry)、[SQLite DELETE](https://www.sqlite.org/lang_delete.html)

## 同机隔离对照

对照提交 `310f090` 与本轮工作树使用同一 Python 环境、临时同卷目录和各自预热的校验库。每完整枚举来源或目标一次计为一次扫描。计数包括写前、删除前及删除后的复核。计时包括引擎工作，确认在测试中即时应答。

| 操作 | 旧版 | 本轮 |
| --- | ---: | ---: |
| 直接同步，确认前扫描 | 4 次 | 2 次 |
| 直接同步，整轮扫描（含删除） | 10 次 | 8 次 |
| 独立预览后同步，合计扫描（含删除） | 14 次 | 10 次 |
| 独立预览后，点击同步触发的额外弹窗 | 1 个 | 0 个 |

在 20 个目录、1,000 对同路径文件中设置 12 个同大小更新，另有 5 个新增、8 个删除。交替对照各三轮，预览加同步耗时中位数由 0.185 秒降至 0.134 秒，直接同步由 0.131 秒降至 0.110 秒。全部样本复制 17 个文件、删除 8 个文件。

另一组使用 57 个目录，按截图量级构造 28,299 个跳过文件、40 个新增、7 个更新、34 个删除。单次对照从点击同步至完成由 5.885 秒降至 3.130 秒，含预览全过程由 8.292 秒降至 5.581 秒。两版均完成 47 个文件复制和 34 个删除。数据来自本机合成样本，实际移动盘速度取决于介质和目录结构。
