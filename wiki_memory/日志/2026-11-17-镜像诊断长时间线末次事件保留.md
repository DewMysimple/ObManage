# 镜像诊断长时间线末次事件保留

准备完整复制和后验哈希时，发现固定 256 条时间线若先被进度填满，后续阶段结束事件也会丢失。限制普通进度为前 224 个槽，保留末次阶段事件；极端情况下优先淘汰进度，整体仍有界。不影响引擎调用、确认、文件操作或计量时钟。

新增长轮次隔离测试，注入 1,000 条匿名进度并检查全部阶段终态仍保留；最终诊断专项 38 项通过，3.73 秒。此前完整回归为 850 项通过，本次只修改工具事件保留逻辑；真实设备状态和报告继续留在忽略目录。

重新运行 tools/build.py，使用原干净子进程 PATH。最新 ZIP 为 236 项、51,034,384 字节，CRC、平铺根层、解压 EXE 启动及隔离 deep 预览通过；演示来源保持不变，缺失目标未创建。详见[入口](../../tools/profile_mirror_once.py)和[测试](../../tests/test_profile_mirror_once.py)。提交与远端结果以最终 Git 核对为准。
