# 工作日志说明

日志按一次实质任务记录目标、决定、修改、实际验证和后续，不承担当前有效事实的唯一来源。[工作日志 MOC](./MOC_工作日志.md)是唯一索引，由工具生成。

命名使用 `YYYY-MM-DD-任务标题.md`，同日重名追加编号。进行中使用 draft，结果补齐才 archived；封存后新增更正日志链接旧页，不改写历史。每篇只使用一个主要 kind：feature / ui / bug / discussion / test / maintenance。

本项目建记忆前已有两个 Git 提交：`fe2dd33` 建立增量镜像应用，`25717b1` 增加往返方向控制。它们是可追溯的代码历史，本次不伪造当时逐轮测试/构建日志。

工作日志不保存完整聊天、私有笔记路径或大量终端输出。规则见[AGENTS](../AGENTS.md)，格式见[日志模板](../模板/日志模板.md)。
