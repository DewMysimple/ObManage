# 普通镜像单次诊断与真实预览

按用户任务书审阅 GUI、普通镜像、扫描/读取/复制、SQLite、默认实例锁及部署/遗留隔离恢复门禁。新增普通镜像单次诊断入口，默认只读，执行只接受同进程新计划和本地 console 现场短语。错误、取消和未运行项分别记录，不能把报告生成成功当作同步成功。

复用 ScanMetrics，补充分端扫描/哈希、流水线墙钟、删除与删除后复核，以及 SQLite 调用与显式提交计时。只保存固定范围的聚合和首末时点；诊断上下文通过现有 copy_context 进入两类 worker。同步算法、暂存 SHA-256、原子替换、逐文件基线、安全屏障和停错规则保持。

真实本机只读预览已运行，来源清单末次复核通过；目标及其直接父目录缺失，工具按默认边界拒绝写入，结果 BLOCKED。私有计划、脱敏 JSON、时间线、热点、机制、报告和分享摘要留在本机忽略目录，没有提交设备报告或私人路径。尚未获得补充父目录授权及本地现场执行短语；真实复制、快速后验复扫、deep 和独立后验审计均为 NOT_RUN。

诊断专项最初 30 项通过；在真实预检发现 Qt 当前 getLockInfo 返回三元组，修正调用并增加真实 QLockFile 测试后 31 项通过。此时全量回归 844 项通过，64.65 秒。补充父目录的显式意图、拒绝和并发出现保护后，专项 35 项通过。最后增加 console 等待的主动过期/取消及退格输入测试，避免无人确认时一直占有应用锁；最终专项 37 项、镜像/路径/扫描/基线组合 186 项通过。最终全量 850 项通过，64.86 秒，无失败或跳过。

基于最终源码运行 tools/build.py，保留原干净子进程 PATH。便携 ZIP 含 236 项、51,034,600 字节，CRC 和平铺根目录通过。解压 EXE 的启动截图和隔离 deep 只读预览均退出 0，演示来源保持不变，缺失目标未创建。68 页工程记忆、文档链接及差异格式检查通过。提交与推送凭据以最终 Git 远端核对为准。

完成真实写入只需在明确父目录准备范围后，于本地交互 console 运行新预览并现场输入对应短语；已有预览不能加载执行，代理不得代输。用户拒绝、期限内未输入或安全复核失败时继续保留 BLOCKED / CANCELLED，不用历史数据补齐未测项目。

说明见[诊断文档](../../docs/仓库镜像单次诊断.md)，隔离测试见[专项回归](../../tests/test_profile_mirror_once.py)。
