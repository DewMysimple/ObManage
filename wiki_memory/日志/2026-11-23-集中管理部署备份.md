# 集中管理部署备份

`.comSync` 的同步前子树和回退保全副本保存在状态目录的 `backups`。目标卷临时目录支持原子切换和故障恢复。完整部署或回退结束后集中保存，应用空闲时也迁移已有可核验的副本。同卷保留目录身份，跨卷复制并校验全部普通文件与目录清单，认证新副本后才删除原副本。跨卷回退把完整副本校验暂存到目标卷并登记恢复身份，再切换。未知路径、异常待恢复和清单无法核验的 NTFS 备用数据流受到保护。备用数据流的识别依据见 [Windows 文件流枚举](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-findfirststreamw)。

保留期限默认关闭，在“事务处理”页应用 1–36500 天后，可删除到期且已核验的成功部署或已结束事务的集中副本。成功部署先持久化结束状态，删除副本后再移除记录，清理只涉及程序备份目录。保留期应用前后不影响手动处理入口。移除左下角“待恢复事务”提醒，保留“事务处理”导航、写入门禁和操作日志。

对用户指出的旧副本只读核验了认证记录、实际目标磁盘和目录身份及完整文件清单。该副本符合启动维护迁移条件。实际迁移和到期清理验证使用隔离目录。设计见 [ADR-010](../决策/ADR-010-事务结束与备份清理解耦.md)。

全量 907 项测试通过。其中覆盖历史认证兼容、复制与登记中断重试、跨卷恢复及提交后的身份复核、到期期间目标变化、未知副本与 NTFS 备用数据流保护。Windows 原生界面检查 980×620、1140×920 和最大化八页，核对事务页路径及设置可访问、左下角提醒已移除。隔离的两块 NTFS 卷验证双向复制、源数据保护和回退保全。

基于最终程序源码运行 `tools/build.py`。便携 ZIP 为 236 项、51,084,784 字节，SHA-256 为 `751d07f0721403d66f2e518dbc203a357ca48ef600e069c9ca4a668a18a49e76`。ZIP CRC、平铺根目录和解压 EXE 原生启动通过。解压 EXE 在隔离状态下实测默认关闭时启动迁移历史副本，及启用后到期清理且保留当前仓库后续编辑；同卷与跨卷两组均通过。
