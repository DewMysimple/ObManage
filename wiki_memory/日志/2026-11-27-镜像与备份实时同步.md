# 镜像与备份实时同步

按两份需求核对现有单向镜像、定时任务、校验基线与托盘行为，将实时同步接入镜像和无视频备份两页。完整镜像包含视频，轻量备份保留目标视频及其承载目录。首次确认已有差异，以后按已保存的本机变化自动执行。两页各自记录绑定、待办和最近成功时间。

普通笔记保存按路径核对两端，暂存并校验后替换。写入句柄尚未关闭则留待重试，其他稳定文件可继续。原盘重连、启动及通知丢失会补查。独立目标修改只提示；空来源或异常批量删除会持久保留人工处理状态。实现入口和调研来源见[调度知识页](../知识/模块/方向界面与调度.md)。

实盘测试在 USB 总线的 exFAT 移动硬盘新建独占临时目录，以本机 NTFS 临时来源运行两种模式。两轮均完成单笔记保存、独立硬盘编辑保护、大小写改名、跨名称移动及延迟删除。另有 256 个不变文件逐项比对，单笔记保存时启用禁止全树枚举的断言。已清理测试目录。

Windows 原生界面在 980×620、1140×920 和 2560×1440 全屏下检查了全部八页，页面均无横向溢出。以最终 ZIP 解压的 EXE 分别开启镜像和备份，连续两次保存后，两种模式均在距最后一次保存 3.25 秒内从 USB 目标读回最终内容。两个页面均通过关闭到托盘后继续同步、独立硬盘改动保留、进程终止期间的本机编辑在重启后补齐，以及暂停后退出。两个测试位置已清理。拔盘、原盘换盘符与原位置换成其他目录使用隔离测试模拟；实盘测试期间设备保持连接。

全量回归最终通过 1032 项（79.41 秒）。较早一轮并行构建时，原有仓库统计的同大小、同修改时间并发改写测试曾失败一次，该用例独立复查和最终全量均通过。覆盖本次机制的用例见[实时引擎测试](../../tests/test_realtime.py)和[页面与调度测试](../../tests/test_realtime_page.py)。2.9.0 便携包已检查 ZIP 根层、全部 236 个条目的 CRC、使用说明、解压 EXE 的八页启动和只读完整内容预览。
