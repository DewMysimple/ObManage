# 2026-09-14｜有界验证复制流水线

## 目标

在 2.1.1 已明显改善 16,320 文件、5.6 GB 无视频备份的基础上，继续在不减少 SHA-256、路径身份与故障屏障的前提下提高镜像和无视频备份效率。

## 实现

- 异卷复制使用一个来源写 worker，最多提前暂存下一文件，使下一文件来源读取/目标写入与当前临时文件写后读取校验重叠；同卷保持串行，提交、公开进度与 SQLite 均在主执行线程。
- 临时文件仍先精确持久登记。失败或取消先汇合 worker，再按路径与身份清理；当前校验失败时，下一文件即使已暂存也不会提交，后续删除不会开始。
- 安全子路径调用返回同次观察的快照，消除紧邻的重复 `lstat`，不跳过祖先链。已验证副本的基线写入与临时所有权撤销在一个 SQLite 事务内完成。
- 无删除任务把复制后的来源/目标完整复核直接作为最终屏障，不再在没有任何文件系统写入的情况下连续重复同一轮全树扫描；有删除时仍保留删除前后两轮。
- 无视频目标保护目录由遍历所有视频目录改为沿当前路径祖先查询集合，保留相同大小写与祖先保护语义。
- 版本更新为 2.1.2，并同步产品文档与工程记忆。

## 验证

- 新增流水线时序、同卷串行、校验失败清理下一暂存、无删除/有删除扫描次数和 SQLite 原子收尾回归。
- 最终完整 pytest 为 371 项通过，覆盖镜像双向、无视频范围、路径/卷变化、并发来源写、目标复读失败、前瞻 worker 取消与汇合、磁盘错误、恢复临时项、删除前后复核和 SQLite 回滚。
- 600 个 4 KiB 新文件、无删除、最终串行分支五轮为 3.432、3.430、3.435、3.451、3.423 秒，中位数 3.432 秒；相对 2.1.1 的 3.823 秒中位数约缩短 10%。异卷流水线必须由真实不同介质复测，同一物理盘伪装两个卷的微基准不作为收益承诺。
- 曾尝试复用 Windows `DirEntry.stat()` 的枚举缓存，但本机返回的文件身份与独立 `lstat` 不一致并触发 58 个安全回归，已完整撤回；最终实现保留独立身份读取。
- 记忆索引刷新完成，lint 通过 42 个 Markdown 页面。
- `tools/build.py` 以 PyInstaller 6.22.0 / Python 3.14.2 成功生成 2.1.2 便携目录与根层平铺 ZIP。冻结 EXE 冒烟退出码 0，截图 78,916 字节，无残留进程。
- ZIP 共 236 项且 CRC 全部通过；根层含 `ObManage.exe`、`_internal/`、使用说明、第三方声明与许可证，不含 `ObManage/ObManage.exe`。最终 ZIP SHA-256 为 `D9673FCA10625568657DCE2B6354016608E992FBA91E61F23D0E93E7A597FDD4`；最终 EXE SHA-256 为 `6742D376812D1278838F070AA802D2A92B1E69BB943C82E37917504B597D73CD`。

## 结果

2.1.2 在不减少目标写后 SHA-256、逐文件路径身份和故障停止删除的前提下，减少无删除备份的重复全树扫描与相邻元数据调用，并为真实异卷提供一个文件深度的 I/O 重叠。所有运行验证均使用隔离临时目录及演示状态，没有执行真实用户仓库、移动盘镜像、部署或清理。
