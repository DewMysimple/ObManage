# 重复启动聚焦窗口

## 目标

当 ObManage 已在同一状态目录运行时，再次打开 `ObManage.exe` 应将已有窗口恢复、置顶并激活，不创建第二个 GUI 实例。

## 决策与改动

- 保留 `QLockFile` 作为单实例所有权和 CLI/GUI 任务互斥边界。
- GUI 主实例在取得锁后监听由状态目录绝对路径哈希得到的 `QLocalServer` 通道。
- 后续启动在锁失败时连接该通道；主实例收到连接后调用窗口已有的恢复/置顶/激活逻辑。连接失败才保留原有提示框兜底。
- `tests/test_app.py` 增加本地 IPC 通知回归测试，并在使用指南、Windows 打包排障和运行架构中记录行为。

## 实际验证

- `tests/test_app.py`：4 passed。
- 完整回归：`333 passed in 55.05s`。
- 记忆检查：`memory_lint.py index` 重建工作日志索引，`memory_lint.py check` 通过 35 个 Markdown 页面。
- `tools/build.py` 成功生成 `dist/ObManage/ObManage.exe` 和根目录平铺的 `dist/ObManage.zip`；PyInstaller 日志确认收集 `PySide6.QtNetwork`。
- 冻结版烟测使用隔离状态目录退出码为 0，并生成 78,055 字节截图；冻结版先后启动两次时第二进程退出码为 0，运行中只保留一个主进程。

## 结果

同一状态目录的重复 GUI 启动现在请求已有窗口聚焦并立即退出，单实例约束继续由锁保证。
