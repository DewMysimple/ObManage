# 事务管理独立页面与清除

## 目标与实现

用户要求移除同步页常驻的“事务处理与保留副本”，改为独立“事务处理”页，并保证记录可以清除。版本 2.6.0 增加第八页；复用既有部署与旧版隔离恢复控制器，通过原全局 worker 处理，恢复任务日志归属独立页。

- 已结束部署事务重新检查后，可删除全部已认证副本（包含回退保全内容）和记录。完整预复核、逐树重检、路径派生及身份/清单验证保留；不触碰当前仓库或来源。
- 可明确仅删除记录，副本原位保留、继续占用空间，不再提供恢复入口；预览显示的位置记录于本机日志。支持离线和副本变化，仍要求认证有效及事务已结束。
- 所有历史记录均可选择。部署 journal 删除前持久化认证 discarded 意图，再依次删除授权锚点和 journal；中断后允许该特定终态缺少锚点，其他异常继续拒绝。失败不重新阻塞，可以重启重试。
- 旧版隔离批次移到同页，所有备份 finalized 后验证空隔离根并删除记录。新回收站清理仍不生成事务。
- 切页、切批次、改清除方式撤销确认；单任务互斥与不可取消阶段无取消按钮保持不变。
