# 真实首次单向同步实验

读取两块实际设备并独立投影非重叠仓库范围。本机首次复制工具默认只读，现场确认绑定预览，使用原生增量和镜像执行链，增设仅新增计划检查、Windows 独占目录创建及句柄发布。核验独立比较完整普通文件清单和 SHA-256；隔离对照记录首次执行、核验与复扫。

实盘首次预览发现来源变化并停止。后续稳定预览发现 47 个仓库，46 个非重叠顶层及一个嵌套，预期复制 27,531 个文件、42,670,830,705 字节。现场确认超时，移动盘目标集合未创建。本轮实际复制和后验核验未运行。两组合成对照没有支持普通镜像的吞吐补丁。

Windows 全量回归 813 项通过。额外隔离核验包括 Windows 保留名称、大小写冲突、暂存文件身份和管道执行拒绝。便携 ZIP 平铺结构与 CRC 校验通过，解压 EXE 的八页启动及隔离完整内容预览通过。
