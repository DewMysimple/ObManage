# 2026-09-14｜验证复制吞吐优化

## 目标

优化程序中镜像、无视频备份、配置/模板分发和遗留恢复所用的文件复制效率，并消除复制时进度条上方重复阶段文字闪烁及进度回跳。

## 实现

- 新增共享的低分配块复制与来源 SHA-256 内核，覆盖全部运行期复制路径，并正确处理短写与取消。
- 镜像/备份保留目标同目录暂存、关闭后写回读取校验、原子替换和失败停止删除；移除不构成整批断电事务保证的逐文件强制缓存刷新。
- 将完整卷/根复核按最多 16 个文件或 250 ms 合并，长文件替换前和各阶段屏障强制复核；逐文件路径链与来源/目标快照检查不变。
- 分发暂存移除紧接整树 SHA-256 之前的重复逐文件目标哈希，最终完整清单验证、全目标准备与恢复 journal 不变。
- 复制和写后校验映射为单调总体进度；管理 worker 以 100 ms 合并非终态事件，相同状态不重复重绘。
- 版本更新为 2.1.1，并补充 README、便携使用说明、决策和模块记忆。

## 验证

- 同一 Windows 环境、同为 600 个 4 KiB 新文件：修改前执行 10.94 秒；最终代码三轮为 3.760、3.931、3.823 秒，中位数 3.823 秒，约提速 2.86 倍。
- 修改后记录到的复制/校验总体字节单调递增，末值等于计划字节。
- 完整 pytest：363 项通过；覆盖共享复制短写/取消、单调进度、批量根复核、来源/目标变化、断盘、写失败、部署准备/提交/回滚和事件合并。
- 备份页实际 Qt 渲染：980×620、1140×920、2560×1440 的表格列宽分别精确填满 722、892、2322 px 视口，横向滚动均为 0；截图目视检查未见状态区遮挡或布局跳变。
- 记忆索引刷新完成，lint 通过 41 个 Markdown 页面。
- `tools/build.py` 以 PyInstaller 6.22.0 / Python 3.14.2 成功生成 2.1.1 便携目录与根层平铺 ZIP。冻结 EXE 冒烟退出码 0、截图 78,916 字节、无残留进程。
- `ObManage.zip` 共 236 项，根层含 EXE、`_internal/`、使用说明、第三方声明及许可证，不含 `ObManage/ObManage.exe`。最终 ZIP SHA-256 为 `A7FE3204F9FC48488E93A3C1C462285A568E09A65533DCF70D6B41C8BEA0D418`；最终 EXE SHA-256 为 `203E62122D0902DCB6263A71F549053306E37461E29E0246B9849B095E650593`。

## 结果

仓库镜像和无视频备份的大量小文件执行路径取得约 2.9 倍受控中位数提速，配置/模板分发和升级前遗留恢复也使用共享复制实现；复制安全屏障及事务恢复保持。复制期顶部状态稳定、总体进度单调且非终态界面更新受控。所有运行验证仅操作隔离临时目录和演示状态，没有对真实用户仓库或移动盘执行同步、部署或清理。
