# 真实介质扫描诊断与优化

## 目标与结果

基线是 2.8.2 `f1c34ddc01b421ab4fe905af724e932a62df1a10`。在真实 NVMe/NTFS 与 USB/exFAT 上做同路径只读对照，保护区不作为报告、状态或夹具位置。原有任务书目录保留。见[验收文档](../../docs/2.8.3-真实介质扫描诊断与性能验收.md)。

H: 三轮中位数，发现 1.078 → 0.828 秒，元数据统计 5.184 → 4.456 秒，选择器实时就绪 1.151 → 0.837 秒，历史点选填入 1.148 → 0.833 秒。新旧结果等价。E: 的发现小幅加快，选择器结果波动。保留普通祖先实时属性检查，叶目录和其他路径使用原快照。

## 实施

- [只读入口](../../tools/benchmark_real_readonly.py)固定已审计的旧版，交替调用实际只读服务，异常或元数据漂移使样本无效。报告只记录聚合、阶段及状态。
- [路径保护](../../tools/benchmark_readonly_paths.py)验证两个真实范围、卷、目录身份和重解析边界，隔离系统临时状态、报告、旧版加载。保护区未执行实际业务写入。
- [路径祖先检查](../../obmanage/paths.py)仅在扫描会话和统计调用点启用轻量属性查询。叶状态、清单、双端末次、SHA-256 和执行前检查保持既有规则。

## 验证与交付

- 真实 USB 严格 UTF-8 三轮中位数 14.31 → 12.82 秒。两次真实增量对照因本机端元数据变化作废，第二次在末次复核得到不完整批次，零方向获得执行资格。首轮报告的计划集合序列化故障已修正并补回归。最终工具的逐场景范围核验在两端发现及选择器通过。
- 1k 与 10k 隔离基准同路径交替三轮，正常双向计划和统计等价；权限、取消、末次新增和文件改名维持原状态。初次增量计数两版末次各枚举 510 次，哈希字节相等。原始报告留在本机。
- 全量测试 781 项通过、零失败、零跳过。八页三尺寸和选择器全屏共 30 张隔离演示记录。最终 ZIP 平铺根层、236 条目、CRC 和使用说明一致性通过；解压 EXE 八页及隔离深度预览均成功。
- 真实完整内容模式、物理热拔插、设备长时间阻塞和真实业务写入未测。完整数据和复现命令见[验收](../../docs/2.8.3-真实介质扫描诊断与性能验收.md)。
