# 归档工作台与日志筛选

## 用户目标

选择入口缩短为“仓库列表”“当前运行”并适配 UI；Templater 与回收站改为“.Templater”“.Trash”。新增按时间/事件查找的操作日志。参考用户提供的两份 ZIP 打包脚本，新增“.Archive”（用户后续明确首字母大写），支持自选或固定位置、可选百度同步文件夹和客户端联动、视频排除及压缩速度/体积参数。

## 实施

- 九页静态注册与版本 2.4.0；路径按钮保留说明悬停，紧凑排版及自适应分行。显示名变更不改实际 File/Templater 或 .trash 子树和持久设置键。
- 归档使用无 Qt 服务，来源/输出/状态边界、目录卷身份、逐文件句柄和内容摘要、最终清单复核、同卷暂存与独占发布。预览零写，来源只读；视频和恢复目录显示排除，保留空目录、ZIP64、0–9 级别。完整性校验直接读取压缩包，不解压额外副本。
- 自选及百度同步目录分别记忆，可关闭记忆；包名可自定义或自动时间戳。可选客户端路径只有成功后才请求打开；失败保留压缩包，不声称上传完成。
- JSONL 记录明确功能、事件、任务标识和结果；定时镜像忙碌跳过独立归入镜像，不混入活动归档任务，不完整结果标为提醒。旧纯文本按时间/关键词兼容，去除兼容副本重复显示。日志组合筛选与复制全部结果，新日志保留筛选条件；明确轮转保留、显示上限和损坏记录问题。
- Windows 路径 stat 和句柄 fstat 的 ctime 可不同：跨 API 比较共同的设备/文件 ID、大小及 mtime，各自仍保留前后 ctime 与完整内容核验，避免正常文件被误判。

- 最终源码全量 `pytest -q`：482 项通过，78.79 秒。最终补充的定时事件归属及不完整状态回归均包含在本次结果内。
- 归档覆盖 0/1/6/9 四种级别 × 是否排除视频、来源字节/mtime/身份不变、空目录/空仓库、中文与长路径、ZIP64 写入、旧时间戳、来源变化、已存在/抢占同名输出、磁盘身份变化、校验损坏、校验后篡改、取消、仅清理本次临时包、遗留恢复门禁。

- 九页布局回归覆盖 980×620、1140×920、2560×1440，另验证启用百度联动时的归档底部动作、表格宽度、日志自选时间控件边界。原生截图检查小窗口、普通窗口及实际最大化 2560×1417；更新全部公开演示图并新增归档/日志图。

## 边界

不提供云上传凭据或自动配置网盘同步；用户自行选择已启用同步的目录。并发写入的 Obsidian 配置可能使来源复核失败；暂停来源写入后重试。强停/断电残留的未知临时包不自动猜测删除。日志有限轮转，不宣称无限历史。
