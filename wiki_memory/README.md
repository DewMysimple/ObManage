# ObManage 工程记忆

此目录保存 ObManage 的当前事实、长期决策、维护知识和工作日志。面向使用者的产品介绍在[项目 README](../README.md)，面向协作者的读取和更新协议在[AGENTS.md](./AGENTS.md)。

以本仓库当前源码、测试、用户明确要求和已验证的运行结果为依据。日志解释结论的来历，不能代替对当前实现的核对。本目录按用户提供的本地工程记忆模板建立，保留 Markdown 分层、来源追溯和无依赖检查；调整了已授权事实的写入流程、GitHub 链接与提交约束。

## 维护

从仓库根目录运行，脚本只使用 Python 标准库：

```powershell
.\.venv\Scripts\python.exe wiki_memory\工具\memory_lint.py index
.\.venv\Scripts\python.exe wiki_memory\工具\memory_lint.py check
.\.venv\Scripts\python.exe wiki_memory\工具\test_memory_lint.py
```

`check` 验证页面字段、日期、链接、来源链接、重复有效主题、重复 ADR 编号和孤儿页；它不验证文字是否真实，也不代替产品测试。`index` 只更新单一日志索引。新页面使用[知识页模板](./模板/知识页模板.md)、[决策模板](./模板/决策模板.md)和[日志模板](./模板/日志模板.md)。
