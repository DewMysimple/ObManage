# 系统架构

## 应用壳与任务

[`pages/registry.py`](../../obmanage/pages/registry.py) 以静态顺序注册六页，保证冻结包可发现全部实现；[`ui.py`](../../obmanage/ui.py) 创建固定左侧导航、镜像页及五个可滚动管理页。镜像保留历史验证过的 `SyncWorker(QThread)`；其他页面通过 [`FeatureWorker`](../../obmanage/tasking.py) 运行无 Qt 服务。两类 worker 共用一个应用任务槽，页面可切换，但不会并发执行两个任务。

全局忙碌状态同时禁用相关页面写入口；只有底层实际接收取消事件的任务才显示全局取消。有部署 journal 或升级前遗留回收站隔离批次待处理，或记录无法安全枚举时，恢复门禁暂停手动/定时镜像和所有新部署、清理；导航提供待恢复入口，各事务页面仍可处理自己的撤销、恢复和确认。定时任务忙碌或被恢复门禁阻止时消费本轮到期事件，不累计补跑。

## 服务层

| 模块 | 职责 / 关系 |
| --- | --- |
| [management/models.py](../../obmanage/management/models.py) | 仓库目录、问题和统计模型 |
| [management/catalog.py](../../obmanage/management/catalog.py) | 物理身份去重的真实仓库发现及打开仓库候选读取 |
| [management/statistics.py](../../obmanage/management/statistics.py) | 严格只读、流式 UTF-8 Markdown 统计 |
| [management/deployment.py](../../obmanage/management/deployment.py) | 限定子树计划、全目标准备、提交、回滚和清理 |
| [management/journal.py](../../obmanage/management/journal.py) | 部署批次、授权锚点、完整性认证和原子更新 |
| [management/trash.py](../../obmanage/management/trash.py) | 根级 `.trash` 完整预览、直接清理及 2.0.0 遗留隔离兼容 |
| [engine.py](../../obmanage/engine.py) | 单向镜像扫描、增量内容判断和只写目标执行 |
| [paths.py](../../obmanage/paths.py) | 长路径、最终路径、包含关系、重解析点和物理身份复核 |

统计只读数据流：集合根 → 仓库发现 → 嵌套仓库边界 → Markdown 元数据/可选内容读取 → 汇总及显式问题。

部署数据流：来源/固定组件/显式目标 → 文件和目录预览 → 复核 Obsidian 占用、路径和卷 → 每目标同卷暂存及 SHA-256 → 全部准备屏障 → 目录改名提交 → 保留旧目标 backup → 撤销或确认清理。回收站数据流：仓库发现 → 精确根级 `.trash` 内容哈希清单 → 默认选择全部非空项 → 不可恢复确认 → 全部所选预览重扫屏障 → 按原清单直接删除 → 保留 `.trash` 根。执行期新增内容不进入删除授权；部分失败报告已删数量后要求重新扫描。

## 设置与持久状态

[`settings.py`](../../obmanage/settings.py) 保存 schema v2 文档：`ui.selected_page`、`features.mirror` 和各管理页命名空间。旧平面镜像设置读入后兼容运行，第一次写 v2 时保留一次 v1 备份；单个功能字段损坏不清空其他功能。

程序数据默认位于 `%LOCALAPPDATA%/ObManage`，包括设置、SQLite 镜像基线、部署 journal/授权/密钥、回收站跨进程锁、升级前遗留回收站 journal/隔离/密钥及日志。新回收站清理不创建隔离持久状态。部署恢复目录位于各目标卷的仓库根附近，使用 `.obmanage-deploy-*` 保留命名空间；仓库发现、统计和镜像不进入这些目录。恢复记录与目录身份绑定并使用系统级跨进程锁，但完整性认证不替代操作系统账户权限，具体边界见[已知问题](./已知问题.md)。

## 运行与打包

依赖以 requirements 文件为准：普通 GIL Python 3.14、PySide6、SQLite 和标准库；部署、回收站与镜像引擎不依赖 Qt。PyInstaller `onedir` 输出 EXE 及 `_internal`，由 [manifest](../../windows.manifest) 声明长路径和高 DPI；构建脚本使用干净子进程 PATH。
