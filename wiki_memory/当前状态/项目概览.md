# 项目概览

ObManage 是中文 Windows 桌面镜像工具，支持在本机和移动硬盘之间往返携带 Obsidian 仓库。每次明确选择一个方向，以来源为准，把新增、修改和删除应用到接收方，未变化文件跳过。两侧各自独立的改动不会合并，接收方独有内容会被清理。

当前源码版本为 1.2.0，已有 UI、独立同步引擎、定时/托盘和 Windows 便携构建入口。公开产品说明、工程记忆及精简布局已建立；差异表采用四列并随窗口填满。产品测试、原生 Windows 排版验证、便携打包及 EXE 启动核验已完成，提交/推送进展见[当前待办](./当前待办.md)与[工作日志](../日志/2026-09-10-工程记忆与界面整理.md)。
