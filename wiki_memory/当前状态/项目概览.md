# 项目概览

当前版本 2.2.1 修复 exFAT 大小写改名空操作导致的失败，并将增量页改为默认精确快照基线复用、可选完整校验及单次比较双向计划。实测同组 44 仓库旧版 264 秒，新版已有有效基线复扫 6.2 秒；首次校验仍约 233 秒。详见[修复与性能证据](../日志/2026-09-21-exFAT大小写修复与扫描提速.md)。

ObManage 是面向 Windows 的中文 Obsidian 仓库管理器。2.2.0 包含八个独立页面，仓库镜像固定为第一页。新增仓库增量工作台：只显示两端有差异及异常的对应仓库，由用户逐仓库指定电脑或移动硬盘为源，在同批中按各自方向串行更新；完全一致的仓库隐藏，未选择的仓库不处理。镜像和备份保留有界验证复制流水线、完整写后 SHA-256 和来源只读边界。其他页面提供排除视频的备份、严格只读统计、三类限定子树分发及根级 `.trash` 直接清理。

| 页面 | 当前能力 |
| --- | --- |
| 仓库镜像 | 本机与移动硬盘之间单向增量镜像；来源只读，目标包含删除 |
| 仓库增量处理 | 按相对路径配对、内容比较、逐仓库人工选来源；批量混合方向更新 |
| 仓库备份 | 笔记本与移动硬盘之间镜像非视频内容；两端视频不比较、不复制、不覆盖、不删除 |
| 仓库统计 | 发现真实仓库，汇总全部普通文件容量与类型，并受控并行统计 Markdown UTF-8 字符和可见问题 |
| 模板套件部署 | 明确选择 `.claude`、`.claudian`、`.obsidian`、`File` 组件和目标 |
| Obsidian 配置分发 | 从仓库或 `.obsidian` 来源完整分发配置子树 |
| Templater 分发 | 从仓库、`File` 或 `File/Templater` 来源分发固定子树 |
| 回收站清理 | 预览根级 `.trash`，默认选择非空项，确认后直接且不可恢复地清理 |

所有写页面都先产生文件与目录预览。增量来源及分发目标默认不选；回收站扫描后默认选择全部非空项，但不可恢复确认仍默认关闭。部署使用持久事务；升级前遗留回收站隔离批次仍可兼容恢复或最终清理。有待恢复或无法安全读取的记录时，应用暂停所有新的写入，只保留只读能力及对应恢复动作。2.2.0 工作台初版交付证据见[工作台日志](../日志/2026-09-20-逐仓库方向增量工作台.md)，当前核心行为见 [ADR-009](../决策/ADR-009-逐仓库人工方向增量.md)。
