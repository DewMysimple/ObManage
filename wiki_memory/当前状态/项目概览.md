# 项目概览

ObManage 是面向 Windows 的中文 Obsidian 仓库管理器。2.1.0 包含七个独立页面，仍把仓库镜像固定为第一页，并新增排除视频的双向仓库备份，另含严格只读统计、三类限定子树分发和根级 `.trash` 清理。当前回收站在完整预览和不可恢复确认后直接删除，不再为新操作创建隔离备份。旧版本地工具只作为业务需求来源，没有直接执行或复制其控制台流程、硬编码路径和先删后拷逻辑。

| 页面 | 当前能力 |
| --- | --- |
| 仓库镜像 | 本机与移动硬盘之间单向增量镜像；来源只读，目标包含删除 |
| 仓库备份 | 笔记本与移动硬盘之间镜像非视频内容；两端视频不比较、不复制、不覆盖、不删除 |
| 仓库统计 | 发现真实仓库，汇总全部普通文件容量与类型，并受控并行统计 Markdown UTF-8 字符和可见问题 |
| 模板套件部署 | 明确选择 `.claude`、`.claudian`、`.obsidian`、`File` 组件和目标 |
| Obsidian 配置分发 | 从仓库或 `.obsidian` 来源完整分发配置子树 |
| Templater 分发 | 从仓库、`File` 或 `File/Templater` 来源分发固定子树 |
| 回收站清理 | 预览根级 `.trash`，默认选择非空项，确认后直接且不可恢复地清理 |

所有写页面都先产生文件与目录预览。分发目标默认不选；回收站扫描后默认选择全部非空项，但不可恢复确认仍默认关闭。部署使用持久事务；升级前遗留回收站隔离批次仍可兼容恢复或最终清理。有待恢复或无法安全读取的记录时，应用暂停新的镜像、定时、部署和清理，只保留只读能力及对应恢复动作。2.0.0 发布证据见[升级日志](../日志/2026-09-11-多页面仓库管理升级.md)，回收站策略变更见[直接清理日志](../日志/2026-09-13-回收站直接清理.md)，最新便携包见[构建日志](../日志/2026-09-13-最新便携包构建.md)。
