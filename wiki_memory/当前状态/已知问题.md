# 已知问题与验证边界

| 已知边界 | 实际影响 / 应对 | 依据 |
| --- | --- | --- |
| 日常快速扫描使用元数据快照 | 内容发生变化而受检查元数据仍完全相同，可能继续跳过；用“完整内容校验”绕过记录 | [engine.py](../../obmanage/engine.py)、[深度校验测试](../../tests/test_engine.py) |
| 无跨全仓库事务或文件系统快照 | 取消、失败保留已完成部分；重新分析后继续。使用者持续修改仓库时可能要求重试，不能承诺任何并发下整体瞬时一致 | [执行与复核](../../obmanage/engine.py) |
| 故障自动测试使用注入 | 断盘、卷身份变化、空间不足及占用错误已有模拟；模拟通过不能声称覆盖所有真实 USB 设备和文件系统故障 | [test_engine.py](../../tests/test_engine.py)、[test_roundtrip.py](../../tests/test_roundtrip.py) |
| 大文件按整个文件复制 | 改变的视频会整文件复制，未改变的视频可跳过；没有块级增量 | [复制模块](../../obmanage/engine.py) |
| 只镜像普通文件内容和目录结构 | 不保留 ACL、备用数据流、历史版本，不跟随符号链接或重解析点 | [paths.py](../../obmanage/paths.py)、[复制实现](../../obmanage/engine.py) |
| 空间检查按本轮待复制总大小 | 预检可能比逐文件释放旧版本后的实际峰值需求更保守；当前优先在执行前报明确空间错误 | [execute 的 disk_usage 检查](../../obmanage/engine.py) |

顶部拥挤、重复相对路径列和右侧宽度问题已在 1.2.0 修复，不再列为未解决缺陷。四列表格、列分隔线及长路径访问由[布局测试](../../tests/test_ui_layout.py)覆盖，并完成原生 Windows 普通窗口、较小窗口和真实最大化验证；具体证据见[本轮日志](../日志/2026-09-10-工程记忆与界面整理.md)。
