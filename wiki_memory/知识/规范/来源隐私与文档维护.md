# 来源、隐私与文档维护

产品 README 面向第一次访问 GitHub 的使用者，应先回答用途、同步方向、删除语义和怎么启动；工程细节移到本目录，不要求读者先读聊天或本机环境。

记忆使用仓库相对链接引用源码和测试，不抄大段代码。日志只记录本轮实际动作及可核对结果，来源字段连接事实和历史。历史 commit 可补充追溯，但当前行为仍以现有源码为准。

已实现且有代码依据的行为可以记为 active；用户明确约束同样是有效来源。推测、未来计划和尚未通过的验收不能用“已解决/已通过”表示。draft 日志封存前补齐结果，长期页不要硬编码随着每次改动变化的测试总数。

GitHub 文档和记忆不记录私有笔记名、真实扫描变更列表、机器用户名、身份凭据及私有绝对路径。路径示例用环境变量、虚构本机目录或普通盘符；运行日志和预览截图提交前检查是否包含个人数据。`.gitignore` 只防止默认跟踪，不代替人工审查暂存区。
