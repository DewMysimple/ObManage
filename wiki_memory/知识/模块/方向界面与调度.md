# 方向、界面与调度

## 多页面应用壳

`MainWindow` 使用固定左侧导航和页面栈；页面顺序由 `pages/registry.py` 静态注册，仓库镜像始终为第一页，仓库备份为第二页。页面自己的路径、预览、确认与恢复状态放在各自的设置命名空间中，切页不改变镜像方向，也不复用其他页面的临时确认。

所有写任务共享一个应用级任务槽。镜像继续使用原有 `SyncWorker(QThread)`，管理页面使用 `FeatureWorker`；两者不能并发写仓库。页面只对真正支持安全取消的任务显示取消入口，恢复、最终释放等不可中断阶段不会提供伪取消按钮。

仓库备份页经 `FeatureWorker` 调用相同 `SyncEngine` 的 `no_video` 模式。页面固定两行端点但每轮可选择移动硬盘到笔记本或笔记本到移动硬盘；默认笔记本端为当前用户桌面的 `ObsidianTest`。路径或方向变化会清空计划，离页只撤销破坏性确认。预览表提供待执行、全部、新增、更新、删除、排除视频、跳过和异常分类，并保持目标完整路径可复制和悬停。

任一持久事务处于待恢复状态，或事务记录无法可信读取时，导航会显式标出恢复页，并全局阻止新的镜像、分发和清理写入。阻塞判断必须遍历所有记录，不能只看当前选择的最新一条；定时镜像到期时会消费本次到期事件并记录跳过，不排队补跑。只有全部待恢复记录完成回滚或最终释放后才解除门禁。

## 固定端点与有效路径

`AppSettings` 保留引擎用的有序 source/target；`local_path`、`portable_path` 按 `direction` 派生。`set_endpoints` 接受固定本机/移动盘路径，`set_direction` 不交换界面行，只转换有效路径。端点或方向变化立即清除自动绑定并关闭定时。

旧配置没有 direction 时保留旧 source/target 的实际方向；对默认移动盘到系统盘场景识别为 to_local，未知自定义组合保持来源作为本机。旧版定时始终暂停，避免升级后静默执行误判方向。不要按所有自定义盘符推测用户工作流程。

## UI 生命周期

`MainWindow._paths()` 是镜像页当前有效方向入口。路径或方向变更使旧预览与本轮勾选失效；`start_sync` 内部也检查确认，不能只靠按钮 disabled。执行时控件禁用，worker 完成后才清理线程和接收结果。

`SyncWorker(QThread)` 在 `run()` 内创建引擎，发信号给主线程，约 80 ms 节流进度，防止大仓库扫描挤满 GUI 队列；`FeatureWorker` 以约 100 ms 合并所有非终态事件，阶段变化不再绕过节流，终态立即发送。镜像的复制和写后校验映射为单调的全轮逻辑字节，相同顶部状态不重复设置文字或样式。取消通过 `threading.Event`，退出中先安全停止任务。不要对正在工作的线程强行 terminate。

## 预览布局与完整路径

`PlanTableModel.HEADERS` 固定为“操作 / 实际修改位置 / 大小 / 说明”。顶部集中展示方向与精简读写提示，完整根路径保留在输入框和悬停提示中；每行操作仍明确接收方。默认只显示待执行项，跳过文件可以单独筛选。

`ResponsivePlanTableView` 根据当前 viewport 宽度分配列宽，操作/大小列固定，剩余宽度按约 68% / 32% 分给路径/说明。窗口变化、筛选带来的纵向滚动条出现或消失，都触发重新计算；表格最后一列贴合右侧，不需要横向滚动。单元格和表头用浅色右边框显示列分隔。

超长路径只在视觉上从中间省略，模型和悬停提示保留完整目标及来源路径。选中行后可用右键复制完整实际修改位置；相对路径仍能从右键获取，但不占独立显示列。修改列序时用模型列常量，并同步检查筛选后的复制映射，防止复制错行或截断路径。

[布局测试](../../../tests/test_ui_layout.py)与[仓库备份页面测试](../../../tests/test_backup_page.py)覆盖普通/较小/大窗口、七个页面的横向溢出与底部动作可达性，以及镜像/备份页的筛选、空状态恢复、列宽填满、操作按钮可见、来源只读方向、长路径复制和截图像素分隔线。

## 定时与托盘

`Scheduler` 只计算本地时间的到期状态，不直接访问文件系统；间隔/每日模式都不积压错过的任务。UI 到期时若忙即跳过，空源会清空目标时暂停定时，盘离线失败保留下次检查。

开启定时或任务运行中关闭窗口会留在托盘；托盘不可用时保留窗口。托盘立即操作目前打开窗口并分析，手动更新仍需本轮方向确认。显式退出停止本次进程；没有 Windows 服务或开机自启。
