# ObManage · 仓库镜像

一个中文 Windows 桌面程序，将源文件夹单向镜像到你选择的目标文件夹。新增文件会复制，修改文件会更新，源端删除的文件和文件夹也会从目标删除。未变化的文件跳过复制。

## 打开程序

打开便携程序目录中的 **ObManage.exe**。请保留旁边的 `_internal` 文件夹；可以移动整个程序目录，无须安装 Python。

默认源目录是当前用户桌面上的 `Obsidian仓库`，默认目标是 `H:\ObsidianVault\Obsidian仓库`。可以修改两个路径，目标选择的是最终镜像文件夹，程序不会额外套一层目录。

## 日常使用

1. 选择源文件夹和目标文件夹。
2. 点击 **分析差异**，查看新增、更新、删除、跳过数量和文件明细。
3. 点击 **开始同步**。执行时可以查看进度、当前文件、速度与结果，也可以取消。

源文件夹是唯一依据：目标里单独添加的文件也会被删除，目标里修改过的文件会按源端内容更新。因此请把目标文件夹专门用于镜像。操作范围限于你选择的目标目录，不会反向修改源文件。

首次接管已有副本时，程序会读取同大小文件进行 SHA-256 内容比较。内容相同就建立记录、跳过复制，即使 NTFS 与 exFAT 的时间戳不同。首次校验可能较慢，读取校验不等于重新复制；取消后可复用已完成的校验记录。

后续运行分别检查两边与上次记录的大小和精确修改时间，未变化的大文件不会再次读取内容。**完整内容校验**会重新读取内容、生成差异预览，用于发现内容已变但大小和修改时间均未变的情况；校验后仍需点击开始同步才会修改目标。

取消或失败时，结果会显示已完成和未完成的部分。已完成文件不回滚；未完成的普通文件先写临时文件，成功后才替换旧文件。再次分析并同步即可继续。新增、更新失败时不再进行后续删除。文件与目录同名的冲突需要先手动处理后重新分析。

## 定时与托盘

默认关闭定时。可以开启“每隔若干分钟”或“每天指定时间”，使用电脑当前本地时间。

- 开启定时后，关闭主窗口会留在右下角系统托盘，继续按时同步。
- 托盘可以打开窗口、立即分析同步、暂停定时或退出。
- 明确选择退出会停止后台定时；本版本不安装 Windows 服务或开机启动项。
- 一次只执行一个任务。运行中不能切换路径，到点时若已有任务就跳过本次，不累计补跑。
- 修改源或目标路径会清除旧预览并暂停定时，需要重新开启以绑定新路径。
- 磁盘未连接时跳过本次，下一次到点再检查。空源需要清空目标时，定时暂停，需在主窗口手动确认。

## 同步范围

包含隐藏文件、Obsidian 配置、空文件夹和所有普通子目录。支持中文及 Windows 长路径。目录链接、符号链接和其他重解析点会明确报错，不跟随链接访问范围之外的数据。

这是普通文件内容及目录结构的镜像，目标可直接浏览、打开。文件发生内容变化时按整个文件复制，一般重命名按新路径复制、旧路径删除处理；仅大小写变化时直接改名，不重拷内容。不进行视频内部的分块复制，也不复制 NTFS 权限、备用数据流或历史版本。

运行时源文件若仍在变化，程序会检查并报告不稳定文件，避免把这一轮误报为完整成功。源文件夹不存在、扫描失败、磁盘身份变化或路径范围不正确时会停止操作。

## 设置与日志

设置、SQLite 同步记录和轮换日志存放于 `%LOCALAPPDATA%\ObManage`，不会写进你的源仓库或镜像内容中。界面提供本次任务日志，`obmanage.log` 保存持久运行记录。

## 从源码运行与构建

需要普通 GIL 版 Python 3.14 x64，在项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m obmanage
```

测试及打包：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tools\build.py
```

产物位于 `dist\ObManage\ObManage.exe`。构建目录以 `onedir` 形式保留动态 Qt 库，未请求管理员权限，EXE 声明支持长路径和高 DPI。

只读预览命令（会更新本机校验记录，但不写入源或目标）：

```powershell
.\.venv\Scripts\python.exe -m obmanage --preview --source 'C:\Users\Administrator\Desktop\Obsidian仓库' --target 'H:\ObsidianVault\Obsidian仓库'
```

加 `--deep` 可强制完整校验，加 `--state-dir` 可将测试记录隔离到指定目录。命令行只提供预览，不提供直接删除或执行镜像的入口。
