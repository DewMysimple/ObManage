# ObManage

**在 Windows 电脑与移动硬盘之间，带走或带回你的 Obsidian 仓库。**

ObManage 是一个中文桌面增量镜像工具。选择哪一边作为来源，它就把另一边更新成同样的文件状态：**新增会复制，修改会更新，删除也会同步；未变化的视频和旧文件会跳过复制。**

整个过程在本地完成，无须云账号。镜像结果是普通文件夹，可直接用 Obsidian 打开。

![ObManage 界面：移动硬盘到本机的差异预览](docs/images/main-window.png)

*界面使用演示数据。预览中的操作均针对本次目标仓库，来源只读取。*

## 适合什么场景？

你在主机上写笔记，把仓库同步到移动硬盘，再带到笔记本继续工作。回来后，可以把移动硬盘上的最新内容和删除状态同步回主机。

| 本次选择 | 以谁为准 | 新增、覆盖、删除发生在哪里 |
| --- | --- | --- |
| 带到移动硬盘：本机 → 移动硬盘 | 本机仓库 | 仅移动硬盘仓库 |
| 带回本机：移动硬盘 → 本机 | 移动硬盘仓库 | 仅本机仓库 |

例如，选择 **H → C**：H 中新增的笔记复制到 C；H 中已删除、C 中还保留的笔记从 C 删除。H 中的来源文件不会被同步操作覆盖或删除。

**每次同步都以选定来源为准。** 目标单独添加的文件也会被删除，目标上较新的修改不会自动优先。它适合轮流在一端工作、再镜像到另一端；不合并两端各自独立的修改，也不保留历史版本。

## 能做什么？

- **先预览，再更新**：查看新增、更新、删除、跳过数量和待复制大小；默认只展示待执行变化。
- **增量复制**：相同内容跳过，首次接管已有副本也无需重新写入整个仓库。
- **完整仓库镜像**：包含子目录、隐藏文件、`.obsidian` 配置和空文件夹；支持中文及 Windows 长路径。
- **明确方向**：本机和移动硬盘的路径固定显示，切换“带走 / 带回”即可改变方向。
- **可取消、可继续**：显示进度、速度与失败原因；重新分析后可继续处理未完成的变化。
- **定时与托盘**：支持间隔或每日同步，默认关闭；切换方向或路径会暂停定时。

## 开始使用

### 已有便携程序

打开便携目录中的 `ObManage.exe`。保留旁边的 `_internal` 文件夹，移动时复制整个程序目录；运行便携版无须安装 Python。

1. 选择本机仓库和移动硬盘仓库。**所选文件夹就是镜像根目录**，不会自动再套一层。
2. 选择“带到移动硬盘”或“带回本机”，核对当前来源与目标。
3. 点击 **分析差异**，查看将要修改的目标文件，尤其是删除项。
4. 勾选本轮方向确认，点击 **更新本机** 或 **更新移动硬盘**。

主机与笔记本都使用本地副本时，完整流程是：主机带走 → 笔记本带回 → 笔记本工作后带走 → 主机带回。如果直接在移动硬盘仓库里工作，则省去笔记本上的复制步骤。

详细操作、定时说明与常见问题见 [使用指南](docs/使用指南.md)。

### 从源码运行或打包

环境：**Windows x64、Python 3.14（普通 GIL 版本）**。界面使用 PySide6，同步记录使用 SQLite。依赖版本固定在 requirements 文件中。

```powershell
git clone https://github.com/DewMysimple/ObManage.git
cd ObManage
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m obmanage
```

生成便携程序：

```powershell
.\.venv\Scripts\python.exe tools\build.py
```

产物位于 `dist\ObManage\`。Git 源码仓库不跟踪构建产物；下载源码后需执行上述构建步骤才能得到 EXE。

## 为什么不会反复复制大文件？

首次遇到已有副本时，同路径、同大小文件会做 SHA-256 内容比较：内容相同就跳过复制并记录两边的文件状态。首次校验会读取文件，**读取校验不等于重新复制**，取消后已完成的记录可以复用。

后续分析分别检查两边的大小与精确修改时间。与各自记录一致的文件直接跳过，从而避免不同文件系统的时间差导致反复复制。任一边发生变化，就重新比较；切换方向也可以复用两端版本均未改变的已校验记录。

“完整内容校验”会绕过快速记录，重新读取两端的每个文件并做 SHA-256，发现大小和修改时间都未改变的内容异常。本机与移动盘位于不同卷时，两端会并行读取，耗时更接近较慢一端而不是两端相加；它没有改成抽样校验，仍会受较慢磁盘的完整读取速度限制。第一版按整个文件增量处理：视频内容发生变化时复制整个视频，不做文件内部的分块同步。

## 可靠性与范围

普通文件先写入目标盘临时文件，完成后再替换正式文件。新增与更新成功后才清理目标多余内容；取消、扫描失败、磁盘断开或复制失败会停止后续删除，已完成部分会明确显示。

程序拒绝源目标相同、互相包含或目标为盘根目录；执行前复核路径和磁盘身份。空来源会清空目标时必须额外手动确认，定时任务会暂停。文件与目录同名冲突、目录链接和其他重解析点会报错，不跟随链接越出范围。

镜像包含普通文件内容与目录结构；不复制 NTFS 权限、备用数据流，也不提供历史版本恢复。设置、校验记录和日志保存在 `%LOCALAPPDATA%\ObManage`，按来源、目标和磁盘身份隔离记录。
